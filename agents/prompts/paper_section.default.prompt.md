## 输出要求

只输出一个 JSON 对象，不要任何解释文字或 Markdown 代码围栏，字段如下：

- `content`：本章正文 Markdown。要求：
  - 只写本章内容，不写章标题本身（章标题由系统统一挂载），小节标题用 `###` 起头（如 `### 5.1 问题一模型建立`）；
  - 书面学术语言成段展开，不要通篇要点罗列；目标字数 {{target_chars}} 字（允许 ±30%）；
  - 数学公式一律 LaTeX：行内 `$...$`，独立公式 `$$...$$`；涉及模型构建时必须给出目标函数与约束的公式化表述；
  - 符号只准使用上方符号约定中的记号；确需新符号时必须在正文中先行定义；
  - 数据表用 Markdown 表格，表格前一行单独写表题「表 N 标题」（N 为全文连续编号），正文引用时写「表 N」且编号必须与表题一致；不要引用本章与前文都没有的表；
  - 图件：只准插入材料「可用图件清单」里、且本章写作指令分配给本章的图；插图独立成段写 `![图 N 标题](文件名)`——`图 N` 的编号与文件名逐字照抄清单（不得改编号、不得换文件名或加路径），标题按清单说明拟一句（不超过 20 字）；正文解读时写「图 N」（编号必须与插图 alt 一致）。清单为「无」或本章未分配到图时，不得插入图片、不得写「如图 N 所示」之类的图引用——终稿会逐条核对，引用不存在的图或未插入的编号都会被记为审计发现；
  - 图注：每张插图的下一段是正式图注，以「图 N 标题。」起头，接着写清单「说明」列里给出的事实——该图展示了什么（横纵轴 / 系列）、样本量或种子数、不确定性定义（如「均值 ± 1 SD，5 个种子」；说明写「确定性结果」就照写）、数据来源文件；说明里没有的要素不得补造，宁缺毋编；图注之后再写正文解读；
  - 引用与参考文献：正文引用只准写材料「可引用文献表」里的编号 `[n]`（借鉴该条先例的方法或结论时紧跟句末，如「……采用整数规划建模[1]」），不得写 `\cite{}`、不得引用表外文献、不得自造编号；本章是「参考文献」章时，正文 = 按表逐行写 `[n] 条目`，编号与条目正文逐字照抄、不得增删改、不加评述，也不写小节标题；表为「无」或本章写作指令未要求引用时，不得使用任何引用标记，也不得编写参考文献列表——终稿会逐条核对编号与条目正文，虚构的一律记为审计发现；
  - 所有数值只能来自「可引用的真实材料」——优先引用其中「数字冻结清单」表里的数值并保持原样（不换算单位、不四舍五入、不改精度），其余数字只能是材料原文里已有的；禁止编造材料中不存在的数字，宁可不写数字也不要估一个；
  - 不复述前文已写内容，需要衔接时用一句话引用前文结论即可。
- `digest`：本章 150 字以内摘要（写了什么、给出了什么结论/数值），供后续章节承接与最终统稿使用。
