# ADR-0022：参考图配色与正文圆角

- 日期：2026-09-18
- 状态：已接受（业主明确授权）

## 背景

业主要求首页和其他页面采用所提供截图的配色与右侧正文圆角，并明确保留已有元素、素材与内容。

## 决策

在现有页面上追加共享外观样式：浅冷灰外层、白色正文、冷灰文字与边界、32px 正文圆角及顶部留边。首页输入框同步采用参考图的圆角与中性控件颜色；建模工作台的现有右侧文档面板采用相同圆角。

不改页面结构、文案、素材、字体、列宽、路由、接口和交互顺序。保留状态与图表的语义色以及深色主题。样式先于无障碍覆盖加载，继续尊重增强对比度偏好。

## 验证

### 同日业主复验调整

后续按业主要求将冷灰配色延伸至设置中心：侧栏、选中项、背景、表单、卡片和开关采用共享颜色令牌，仅更改颜色与阴影，不调整设置项、布局或保存逻辑；保留深色模式与品牌、危险操作的语义色。

正文面板仅右上角恢复直角，其余圆角保留；对话标题区移除底部分隔线，右侧操作按钮与侧栏筛选按钮使用透明底色。赛题库、优秀论文、方法库获准优化布局：增加页头和表格留白、允许筛选自然换行、方法标题与操作区回到正常文档流并适配窄屏。现有文本、素材、数据、路由与功能不变。

按现有 14 条路由保留同视口修改前后截图，核对内容和素材不变、关键交互、窄屏与深色模式，运行生产构建和前端检查。截图及验收脚本仅保存在本地 `audit-current/`，不进入 Git。
